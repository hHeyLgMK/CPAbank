# CPAbank 网页与独立题库

发布网址：<https://hheylgmk.github.io/CPAbank/>。

网站在 `codex/github-pages-question-bank` 分支独立维护。`main` 的桌面和安卓构建文件保持原样；网页当前导入本地 3.5.0 的六科题目。网页发布不会自动更新已经安装的 EXE 或 APK。

## 文件在哪里

| 路径 | 用途 |
| --- | --- |
| `site/` | 网页界面、答题和本地记录逻辑；不内嵌题目 |
| `question-bank/subjects/*.json` | 每科独立的题干、答案、解析、章节和题图引用 |
| `question-bank/catalog.json` | 稳定题号、科目顺序、限时练习配置和来源版本 |
| `question-bank/assets/` | 题目图片 |
| `question-bank/downloads/` | 题目清单和学习资料 |
| `scripts/build-pages.mjs` | 校验并生成可直接静态托管的 `_site/` |
| `.github/workflows/deploy-pages.yml` | 测试通过后自动发布优化分支 |

`scripts/import-current-bank.mjs` 是从离线版源码迁移题库的工具，参数为该源码目录。日常发布直接使用已拆分的 JSON，不需要重新执行导入。重新导入会重新生成 `site/app.js` 等文件，应先检查差异。

## 只修改题目

1. 在本分支打开相应科目的 JSON，修改题干、解析或答案。
2. 修正现有题目时保留内部 `id`；新增题目使用不重复的 `id`，并在章节的 `items` 中加入引用。需要显示固定题号时同步维护目录。
3. 新增题图放进 `question-bank/assets/`，题目的 `media[].src` 填写相对于此目录的路径。
4. 提交后 GitHub Actions 会先校验六科、答案范围、图片、练习题号和答题恢复，再发布网站。可在仓库 Actions 中查看结果。
5. 刷新网页，或点击底部“检查更新”。底部显示题库来源版本、题数和内容版本；每次题目改变会自动计算新的内容版本。

仅更新题目、答案或解析时，无须修改 `site/` 程序或手工打包安装程序。改动题库结构时需要同步升级格式校验和加载器。

## 加载与记录

网页启动时读取 `banks/manifest.json`，再下载它引用的按内容版本划分的 JSON。文件通过大小、SHA-256 和结构校验后才整组启用；不会把下载一半的新题库与旧题库混在一起。图片使用内容命名的路径，兼容 `/CPAbank/` 子目录。

最近一组完整验证的题目缓存在当前浏览器的 IndexedDB。新版题库下载失败时，有可用缓存就回退到旧题库并显示提示；第一次访问失败会显示重试入口。浏览器禁止或清空缓存后仍可联网加载。此缓存不包含完整网页和所有题图，因此不承诺网页离线启动。

答题记录和题库缓存分开保存，沿用原有题目内部 ID 与记录格式；题库版本改变不会清空答题记录。退出重进会恢复题目位置、选择、主观题草稿及机考进度。网页有导出/导入记录入口。

记录存于当前浏览器，当前静态站没有账号或手机电脑自动同步。同一浏览器同一站点的记录共享；不同浏览器/设备分别保存。原生应用与网页属于不同存储空间，迁移记录需要使用导出/导入。切换网址也需要迁移记录。

## 本地验证

需要 Node.js 22 或更新版本，无第三方包安装步骤：

```text
node scripts/build-pages.mjs
node --test tests/pages-bank.test.mjs tests/pages-runtime.test.mjs
```

将 `_site/` 用任意本地 HTTP 服务打开。不要用 `file://` 直接打开模块网页。部署流程只上传生成的静态文件，不上传签名私钥、设备证书或刷题记录。
