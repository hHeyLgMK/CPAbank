# 3.3.0：补齐备考计划进阶题，统一知识点索引

版本日期：2026-10-13。Android 版本 `3.3.0`、版本码 `38`；Windows 版本 `3.3.0.0`。

此前逐周备考计划主要能定位零基础题，应用推进、章内小综合和跨章综合缺少可直接作答的配套题。本版按会计、税法和战略的计划范围补入 181 道原创题，题库由 4,412 题增至 4,593 题。

经济法 305 题、财务成本管理 393 题、审计 394 题，三科数量保持不变。新增题覆盖会计 30 章、税法 14 章和战略 8 章，每章均配应用推进与章内小综合。每题提供完整题干、参考答案、解析、评分要点、建议用时以及所用知识点的教材索引。

新增题和限时题组均标为原创练习。它们用于落实计划中的练习层级，不代表穷尽考试规则、例外与综合考法，也不作为历年真题使用。

## 计划与答题入口

- 原备考计划保留原四张表，增加“进阶题定位”和“限时练习”两张表；46 周、三个科目形成 138 行定位，列明配套题号、建议用时和练习说明。
- 新增 12 组原创限时综合练习，每科四组。题组使用固定题目与设定时长，可以继续未完成练习，也可以重做。
- 答题界面增加零基础、应用推进、章内小综合、跨章综合及全部层级筛选，侧边菜单增加“备考计划练习”。层级、题组和剩余时间纳入保存与恢复。
- 提供完整进阶题解、逐周配套题号和统一知识点索引的下载文件，便于离线查阅。

## 来源索引

各科解析统一采用会计题目的索引方式：显示对应章、节、知识点、教材印刷页和 PDF 页。组合题逐项列出所用知识点的来源。

本轮核对并修正已有基础题的来源位置；在能够定位知识点正文时记录单页或多页范围。只能确认所属知识节的题目继续显示真实阅读范围，不把范围起始页当作已核实的知识点单页。索引数据保留以下粒度：

| 粒度 | 含义 |
| --- | --- |
| `topic-page` | 已核实的知识点单页 |
| `topic-range` | 已核实的知识点正文跨页范围 |
| `section` | 所属知识节的阅读范围 |
| `official` | 官方补充来源，保留可回查链接 |

税法扫描资料缺少印刷页 628—629，相关旧题保留官方补充来源。税法题在题干中明确计算假设、适用税率等必要条件，政策来源随题目保留；后续政策变化仍需复核。

## 数据兼容与设备升级

原 4,412 道题保留内部题号、题干、答案和解析正文。旧题号和显示题号继续使用；新增题追加编号，来源索引的修正单独维护。基础题正文校验使用 `content/original-question-core.json`，原 APK 来源记录 `content/android-import.json` 继续保留。

本版新增题和来源索引会改变题库标识。Android 与 Windows 须同时更新为 3.3.0 系列并使用相同题库标识才能同步。Android 沿用原包名和签名证书，覆盖升级时保留原应用数据。Windows 沿用现有设备身份；原有练习记录与会话继续使用稳定题号关联。

## 构建与核查

题库按以下顺序构建：

```powershell
python -X utf8 content/build_bank.py
python -X utf8 content/build_strategy.py
node content/accounting/build.mjs
node content/build_progression.mjs
```

将 `dist/` 的题库模块（含 `progression.js` 和 `question-numbers.js`）、`coverage.json`、CSV 及 Markdown 下载文件同步到 `native/web/`，保留原生目录自己的界面与同步代码，然后构建 APK / EXE。完整命令见 [原生构建说明](../../native/README.md)。

本版自动校验范围包括原题正文基线、题号唯一性、答案有效性、知识点来源结构与页码、每章进阶覆盖、46 周安排、12 个固定题组、练习层级和题组的保存恢复。构建产物应另核对两端题库标识、版本信息与安装包哈希。
